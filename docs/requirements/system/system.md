# 시스템 요구사항 명세

## 문서 정보

- 상태: 사용자 승인 대기
- 수준: 시스템 (전체 프로그램)
- 작성 및 검토: Codex
- 구현 담당: Claude

## 배경

일반 PC 사용자가 별도 서버나 인터넷 연결 없이 기본적인 산술 계산을 빠르게 수행할 수 있는 Windows 데스크톱 계산기가 필요하다. 사용자는 마우스 또는 키보드로 값을 입력하고, 덧셈·뺄셈·곱셈·나눗셈 결과와 오류 상태를 단일 창에서 확인한다.

현재 `src/`와 `tests/`에는 제품 코드나 테스트가 없으며 기존 시스템 요구사항도 없다. 따라서 본 문서가 계산기 제품의 최초 시스템 요구사항 기준이 된다.

## 목표

- 일반 사용자가 별도 학습 없이 사칙연산을 수행할 수 있게 한다.
- 마우스와 키보드 입력을 모두 지원한다.
- 0으로 나누기와 같은 잘못된 연산을 안전하게 처리한다.
- 계산 결과 또는 오류를 입력 후 100ms 이내에 표시한다.
- Windows 10/11에서 서버나 네트워크 연결 없이 동작한다.

## 범위

### 포함 범위

- 덧셈, 뺄셈, 곱셈, 나눗셈
- 정수와 소수 입력
- 계산식의 현재 입력값, 결과 및 오류 표시
- 전체 초기화
- 마지막 입력 문자 한 자리 삭제
- 직전 결과를 이용한 후속 계산
- `=` 반복 입력을 통한 직전 연산 반복
- 마우스 버튼과 키보드를 통한 입력
- 0으로 나누기 오류 처리
- 한국어 사용자 인터페이스
- Windows 10/11 로컬 데스크톱 실행

### 제외 범위

- 삼각함수, 로그 등 공학용 함수
- 괄호 또는 연산자 우선순위를 포함한 복합 수식 편집
- 계산 이력 저장 및 조회
- 앱 종료 후 계산 상태 복원
- 다중 창 또는 탭
- 단위 및 통화 변환
- 프로그래머 계산기 모드
- 사용자 계정, 클라우드 동기화 및 외부 서버 연동
- Windows 이외 운영체제 지원

## 사용자 및 사용 사례

주 사용자는 특별한 기술 지식이 없는 일반 Windows PC 사용자다.

대표 사용 사례는 다음과 같다.

1. 사용자가 숫자와 연산자를 입력하고 `=`를 선택하여 계산 결과를 확인한다.
2. 사용자가 소수점이 포함된 값을 계산한다.
3. 사용자가 직전 결과에 연산자와 새 피연산자를 입력하여 계산을 이어간다.
4. 사용자가 `=`를 반복 입력하여 직전 연산을 같은 피연산자로 반복한다.
5. 사용자가 잘못 입력한 마지막 한 자리를 삭제하거나 전체 입력을 초기화한다.
6. 사용자가 0으로 나누기를 시도하고 오류 안내를 확인한 뒤 새 계산을 시작한다.
7. 사용자가 마우스 대신 키보드만으로 동일한 계산을 수행한다.

### 모듈 간 의존

- `UI`는 사용자 입력을 계산 명령으로 전달하고 표시할 상태를 얻기 위해 `CALC`에 의존한다.
- `CALC`는 사용자 인터페이스 구현에 의존하지 않는다.
- 의존 방향은 `UI → CALC`의 단방향이며 순환 의존은 없다.
- 모듈 분해는 책임 기준의 제안이며 사용자 확인 후 확정한다.

## 정상 흐름

1. 시스템이 초기 표시 상태로 실행된다.
2. 사용자가 마우스 또는 키보드로 첫 번째 수를 입력한다.
3. 시스템이 입력값을 표시한다.
4. 사용자가 사칙연산자 하나를 입력한다.
5. 사용자가 두 번째 수를 입력한다.
6. 사용자가 `=` 또는 이에 대응하는 키보드 입력을 실행한다.
7. 시스템이 선택된 연산을 수행하고 결과를 표시한다.
8. 사용자는 결과를 확인한 후 다음 중 하나를 수행할 수 있다.
   - 연산자와 새 수를 입력하여 직전 결과에 이어 계산한다.
   - `=`를 다시 입력하여 직전 연산을 반복한다.
   - 전체 초기화 또는 새 숫자 입력으로 새 계산을 시작한다.

## 예외 및 오류 흐름

- 두 번째 피연산자가 0인 나눗셈을 실행하면 시스템은 계산 결과 대신 한국어 오류를 표시하고 계속 응답해야 한다.
- 오류 상태에서 전체 초기화를 입력하면 모든 계산 상태를 제거하고 초기 상태로 돌아가야 한다.
- 오류 상태에서 새 숫자를 입력하면 오류를 해제하고 해당 숫자를 새 계산의 첫 입력으로 사용해야 한다.
- 현재 입력에 이미 소수점이 있는 상태에서 소수점을 다시 입력하면 두 번째 소수점을 추가하지 않아야 한다.
- 입력할 숫자가 없는 상태에서 한 자리 지우기를 실행해도 앱이 종료되거나 잘못된 값이 생성되지 않아야 한다.
- 피연산자가 완성되지 않은 상태에서 `=`를 입력해도 앱이 비정상 종료되지 않아야 한다.
- 연산자를 연속 입력했을 때 적용할 구체적인 연산자 교체 규칙은 미결 질문으로 남기되, 앱은 비정상 종료되지 않아야 한다.
- 표시 가능 범위를 벗어난 결과의 처리 방식은 미결 질문으로 남기되, 앱은 비정상 종료되지 않아야 한다.

## 데이터 및 인터페이스 영향

- 영구 저장 데이터는 없다.
- 계산 상태는 앱 실행 중 메모리에만 유지하며 앱 종료 시 폐기한다.
- 최소 런타임 상태에는 현재 입력값, 첫 번째 피연산자, 대기 중인 연산자, 직전 두 번째 피연산자, 직전 연산자, 표시 상태 및 오류 상태가 포함될 수 있다.
- 사용자 입력 인터페이스는 화면 버튼과 키보드다.
- 사용자 출력 인터페이스는 단일 계산기 창의 표시 영역과 한국어 오류 표시다.
- 외부 서버, 데이터베이스, 사용자 계정 또는 클라우드 인터페이스는 없다.
- Electron의 메인 프로세스와 렌더러 프로세스 사이에 인터페이스가 필요할 경우 계산기 기능에 필요한 최소 범위로 제한한다.

## 기존 기능 영향

현재 제품 코드와 기존 시스템 요구사항이 없으므로 영향을 받는 기존 제품 기능은 없다. 루트 `README.md`에 정의된 기술 스택, 지원 운영체제, 오프라인 동작, 한국어 UI 및 성능 목표를 본 요구사항에 반영한다.

## 테스트 관점

- 각 사칙연산은 양수뿐 아니라 음수 결과와 소수 결과를 포함해 검증한다.
- 마우스와 키보드 경로가 동일한 계산 결과와 상태 전이를 만드는지 검증한다.
- 전체 초기화가 현재 입력뿐 아니라 대기 연산, 반복 연산 및 오류 상태도 제거하는지 검증한다.
- `=` 반복은 직전 연산자와 두 번째 피연산자를 정확히 재사용하는지 검증한다.
- 0으로 나누기에서 `Infinity`, `NaN`, 빈 화면 또는 비정상 종료가 발생하지 않는지 검증한다.
- 오류 후 전체 초기화와 새 숫자 입력의 두 복구 경로를 검증한다.
- 앱 종료 후 상태가 남지 않는지 검증한다.
- 네트워크 차단 상태에서 모든 기능이 동작하는지 검증한다.
- 입력부터 화면 갱신까지 100ms 성능 기준을 Windows 10/11에서 검증한다.
- 시스템 테스트 이름 또는 속성에는 대응하는 `SYS-AC-###` ID를 포함해야 한다.

## 위험 요소

- JavaScript 부동소수점 표현으로 인해 일부 소수 계산에서 사용자가 예상하는 십진 결과와 내부 계산 결과가 다를 수 있다.
- 매우 큰 수, 매우 작은 수 또는 긴 소수의 표시 정책이 정해지지 않아 화면 넘침이나 과도한 자릿수가 발생할 수 있다.
- `=` 입력 키, 전체 초기화 키 및 연산 기호의 키보드 매핑이 확정되지 않으면 플랫폼별 입력 동작이 달라질 수 있다.
- 연산자를 연속 입력하거나 두 번째 피연산자 없이 `=`를 입력하는 경우의 세부 규칙이 확정되지 않았다.
- Electron 기반 앱의 패키징과 Windows 환경 차이로 인해 운영체제별 실행 검증이 필요하다.

## 가정

- 계산기는 한 번에 하나의 이항 연산을 입력하고 실행하는 방식으로 동작한다.
- `×`와 `÷`는 화면 표시용 기호이며 키보드에서는 각각 `*`와 `/`를 사용할 수 있다.
- 새 숫자 입력은 0으로 나누기 오류 상태에서 새 계산을 시작한다.
- 계산 결과는 다음 연산의 첫 번째 피연산자로 사용할 수 있다.
- 계산 상태는 앱 프로세스가 실행되는 동안에만 유지한다.
- 네트워크와 외부 서비스는 계산 기능에 사용하지 않는다.
- 모듈 목록은 아직 확정되지 않았으며 `CALC`와 `UI`는 사용자 승인을 위한 제안이다.

## 구현 전 확인 사항

- 사용자가 `CALC`와 `UI` 모듈 분해 및 단방향 의존 관계를 검토하고 확정해야 한다.

- Windows 10/11 검증 환경과 100ms 응답시간 측정 기준을 준비해야 한다.
- Electron, TypeScript, React 및 electron-vite 기반 프로젝트 구조를 확정해야 한다.
